# 🚀 Developer Portfolio

A modern, responsive personal portfolio website built to showcase my projects, skills, and experience as a web developer.

🔗 **[Live Demo](https://your-portfolio-link.vercel.app)** | 📂 **[GitHub Repository](https://github.com/ayishanu17-crypto/my-portfolio)**

---

## ✨ Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Projects Showcase:** Interactive section displaying key projects with live links and tech details.
- **Skills Overview:** Categorized list of technical skills, frameworks, and tools.
- **Contact Integration:** Easy ways for potential recruiters and clients to get in touch.

---

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3 / Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel / Netlify
